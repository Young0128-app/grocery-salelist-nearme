# 동네세일

캐나다 우편번호를 입력하면 주변의 H Mart, Galleria, Metro, Food Basics, Loblaws, T&T 전단 상품을 한곳에서 찾아볼 수 있는 정적 웹앱입니다.

## 사용 방법

1. `내 주변 우편번호`에 캐나다 우편번호를 입력합니다.
2. `세일 보기`를 누릅니다.
3. 마트, 상품 종류, 검색어를 이용해 원하는 상품을 찾습니다.
4. 상품을 누르면 Flipp의 전단 원문이 새 창에서 열립니다.

다른 지역의 우편번호를 함께 입력하면 두 지역의 세일 상품도 비교할 수 있습니다. 마지막으로 입력한 기본 우편번호는 이 브라우저의 `localStorage`에만 저장됩니다.

## GitHub Pages

이 폴더의 파일을 GitHub 저장소에 올린 뒤, 저장소의 **Settings → Pages**에서 배포할 브랜치와 루트 폴더를 선택하면 됩니다. 시작 파일은 폴더 맨 위의 `index.html`입니다.
